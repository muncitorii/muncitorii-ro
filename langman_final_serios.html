2. Capitolul 2. Gametogeneza

Figura ilustrează logic capitolul despre gametogeneză: originea celulelor germinative, ovogeneza, spermatogeneza, meioza și apariția anomaliilor cromozomiale prin non-disjuncție.
Gametogeneză = procesul de formare a gameților masculini și feminini, incluzând meioza și diferențierea celulară.
Ovogeneză = formarea gameților feminini, începută înainte de naștere, cu două blocaje meiotice importante.
Spermatogeneză = formarea gameților masculini, începută la pubertate și continuată apoi în mod constant.
Non-disjuncție = separarea anormală a cromozomilor în timpul diviziunii, cu apariția de gameți anormali numeric.

Ce trebuie reținut

  • celulele germinative primordiale apar la nivelul sacului vitelin și migrează spre gonadele indiferente
  • ovogeneza începe intrauterin, spermatogeneza începe la pubertate
  • ovocitul primar este blocat în profaza meiozei I
  • ovocitul secundar este blocat în metafaza meiozei II
  • trisomiile și monosomiile apar frecvent prin non-disjuncție
  • vârsta maternă crește riscul de anomalii numerice cromozomiale
Ce poate pica: blocajele ovogenezei, diferența dintre ovogeneză și spermatogeneză, ce este trisomia 21, ce este monosomia, ce este non-disjuncția.

3. Capitolul 3. Prima săptămână de dezvoltare

Figura este relevantă pentru finalul primei săptămâni: trofoblastul, blastocistul și începutul implantării în mucoasa uterină.
Fecundație = fuziunea spermatozoidului cu ovocitul, de obicei în ampula trompei uterine.
Clivaj = diviziuni mitotice succesive ale zigotului fără creșterea dimensiunii totale.
Morulă = stadiu embrionar format dintr-o masă compactă de blastomere.
Blastocist = stadiu care conține embrioblast, trofoblast și cavitate blastocistică.

Ce arată figura

Imaginea susține ideea-cheie a capitolului: blastocistul este pregătit pentru implantare, trofoblastul interacționează cu endometrul, iar zona pelucidă a dispărut.

Ce trebuie reținut

ovulație → fecundație → zigot → clivaj → morulă → blastocist → implantare

Ce poate pica: locul fecundației, definiția morulei, definiția blastocistului, diferența dintre embrioblast și trofoblast.

4. Capitolul 4. A doua săptămână de dezvoltare

Figura arată exact structurile esențiale pentru săptămâna a doua: epiblast, hipoblast, cavitate amniotică, citotrofoblast și sincitiotrofoblast.
Disc embrionar bilaminar = embrion format din două straturi: epiblast și hipoblast.
Citotrofoblast = stratul celular intern al trofoblastului.
Sincitiotrofoblast = stratul extern multinucleat al trofoblastului, invaziv, implicat în implantare.

Ce trebuie reținut

  • apare cavitatea amniotică
  • apare sacul vitelin
  • se dezvoltă sistemul lacunar
  • începe circulația utero-placentară timpurie
Formula bună de memorare: săptămâna a doua = implantare activă + disc bilaminar + amnios + sac vitelin + trofoblast diferențiat.

5. Capitolul 5. A treia săptămână de dezvoltare

Figura este centrală pentru capitol: linia primitivă, migrarea celulelor, gastrulația și formarea notocordului.
Gastrulație = procesul prin care discul bilaminar devine trilaminar, cu apariția ectodermului, mezodermului și endodermului.
Linie primitivă = structură apărută pe epiblast, care marchează locul de invaginare celulară.
Notocord = structură mediană mezodermică, cu rol organizator și de schelet axial primitiv.

Ce arată figura

Figura arată apariția liniei primitive și migrarea celulelor care vor forma cele trei straturi germinative. Este una dintre cele mai importante imagini din embriologia generală.

Ce trebuie reținut

  • epiblastul dă naștere tuturor straturilor germinative
  • ectodermul formează SNC, SNP și epiderm
  • mezodermul formează mușchi, os, cord, vase, rinichi și gonade
  • endodermul formează epiteliul tubului digestiv și respirator și glande precum ficatul și pancreasul
Ce poate pica: definiția gastrulației, ce este notocordul, ce formează fiecare strat germinativ.

6. Capitolul 6. Perioada embrionară, săptămânile 3-8

Figura susține partea despre reorganizarea mezodermului, formarea cavităților corpului și începutul sistemului vascular în perioada embrionară.
Organogeneză = formarea primordiilor organelor în perioada embrionară.

Ce trebuie reținut

  • săptămânile 3-8 reprezintă perioada critică pentru malformații
  • mezodermul plăcii laterale se împarte în foiță parietală și viscerală
  • se formează cavitățile corpului și sistemul vascular timpuriu
Foarte important: teratogenii produc cele mai severe efecte în perioada de organogeneză.

7. Capitolul 7. Perioada fetală, placenta și anexele fetale

Figura este relevantă pentru placentă și spațiul intervilos, explicând schimburile materno-fetale și rolul lichidului amniotic.
Placentă = organ temporar feto-matern care permite schimburile dintre mamă și făt și are funcție endocrină.
Lichid amniotic = lichid în care este suspendat fătul, cu rol protector și funcțional.

Ce trebuie reținut

  • placenta la om este hemocorială
  • cordonul ombilical conține două artere și o venă
  • lichidul amniotic amortizează șocurile, permite mișcarea și previne aderențele
Ce poate pica: tipul placentei, componentele cordonului ombilical, funcțiile lichidului amniotic.

8. Capitolul 8. Malformațiile congenitale și diagnosticul prenatal

Figura este foarte utilă pentru grilă, deoarece corelează factorii teratogeni cu malformațiile congenitale tipice.
Teratogen = agent capabil să producă anomalii de dezvoltare.
Diagnostic prenatal = identificarea anomaliilor fetale înainte de naștere prin metode imagistice și genetice.

Ce trebuie reținut

  • rubeola congenitală se asociază cu cataractă, surditate și malformații cardiace
  • alcoolul produce sindrom alcoolic fetal
  • unele medicamente, ca acidul valproic sau izotretinoinul, sunt teratogene importante
  • acidul folic reduce riscul defectelor de tub neural
Ce poate pica: asocierea dintre teratogen și defectul caracteristic.
